# 🚀 Быстрая настройка Postman для тестирования API Шаблонов

## Шаг 1: Импорт коллекции

1. Откройте Postman
2. Нажмите **Import** (вверху слева)
3. Выберите файл `Templates_API.postman_collection.json`
4. Коллекция будет импортирована со всеми запросами

## Шаг 2: Настройка переменных окружения

### Вариант А: Переменные коллекции (рекомендуется)

1. Откройте коллекцию "Templates API"
2. Перейдите на вкладку **Variables**
3. Установите значения:
   - `baseUrl` = `http://localhost:8000` (или ваш production URL)
   - `token` = `YOUR_TOKEN_HERE` (замените на реальный токен)

### Вариант Б: Переменные окружения Postman

1. Создайте новое окружение (Environments → +)
2. Добавьте переменные:
   - `baseUrl` = `http://localhost:8000`
   - `token` = `YOUR_TOKEN_HERE`
3. Выберите это окружение в выпадающем списке (справа вверху)

## Шаг 3: Получение токена

Перед использованием API шаблонов необходимо получить токен авторизации:

**POST** `http://localhost:8000/api/login`

**Body:**
```json
{
  "email": "your-email@example.com",
  "password": "your-password"
}
```

**Ответ:**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": { ... }
}
```

Скопируйте значение `token` и вставьте в переменную `{{token}}` в Postman.

## Шаг 4: Тестирование

Теперь вы можете использовать все запросы из коллекции:

1. **Создать шаблон - Зарплата Цех** - создает шаблон для рабочих цеха
2. **Создать шаблон - Зарплата ИТР** - создает шаблон для ИТР
3. **Получить все шаблоны** - список всех шаблонов
4. **Получить шаблон по ID** - получить конкретный шаблон
5. **Обновить шаблон** - изменить существующий шаблон
6. **Удалить шаблон** - удалить шаблон

## 📝 Примечания

- Все запросы используют переменные `{{baseUrl}}` и `{{token}}`
- При изменении токена обновите переменную `token`
- При работе с production замените `baseUrl` на соответствующий URL

## 🔍 Проверка работы

После создания шаблона проверьте ответ:
- Статус код должен быть `201 Created` для создания
- Статус код должен быть `200 OK` для получения/обновления
- В ответе должны быть данные шаблона с полями `id`, `title`, `templateType`

## ⚠️ Ошибки

Если получаете ошибку `401 Unauthorized`:
- Проверьте, что токен актуален
- Убедитесь, что токен указан в формате `Bearer YOUR_TOKEN`
- Получите новый токен через `/api/login`

Если получаете ошибку `404 Not Found`:
- Проверьте правильность `baseUrl`
- Убедитесь, что сервер запущен
- Проверьте, что ID шаблона существует
